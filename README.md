# Boulangerie Saint-Michel

Site vitrine moderne pour une boulangerie artisanale locale.

## Objectif

Créer un site vitrine élégant, responsive et fonctionnel permettant de :
- présenter les produits
- valoriser le savoir-faire artisanal
- faciliter la prise de contact

---

## Fonctionnalités

- Design responsive (desktop / tablette / mobile)
- Navigation fluide
- Sections : Hero, À propos, Produits, Galerie, Contact
- Formulaire de contact fonctionnel (PHP)
- Envoi AJAX sans rechargement de page
- Feedback utilisateur dynamique
- Footer premium avec branding

---

## Stack technique

- HTML5
- CSS3
- JavaScript (Fetch API)
- PHP
